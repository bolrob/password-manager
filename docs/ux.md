# UX-концепция: PassVault

## Целевая аудитория

### Персона 1 — Дмитрий, разработчик (28 лет)
- **Цели:** хранить десятки рабочих токенов, SSH-ключей, API-ключей; быстро копировать пароли; не держать их в голове.
- **Ожидания:** минималистичный интерфейс, быстрый поиск, клавиатурная навигация.
- **User stories:**
  - *Как разработчик, я хочу фильтровать записи по тегу «dev», чтобы быстро найти нужный токен.*
  - *Как разработчик, я хочу видеть индикатор надёжности пароля, чтобы знать, стоит ли его менять.*

### Персона 2 — Анна, менеджер (42 года)
- **Цели:** хранить пароли от банков, соцсетей, рабочих сервисов; получать напоминания о смене.
- **Ожидания:** понятный интерфейс без технического жаргона, предупреждения об устаревших паролях.
- **User stories:**
  - *Как менеджер, я хочу видеть список устаревших паролей, чтобы знать, что нужно обновить.*
  - *Как менеджер, я хочу установить напоминание о смене пароля, чтобы не забыть об этом.*

## Дизайн-система

Базируется на **Taiga UI 5** (light theme по умолчанию).

| Элемент | Компонент Taiga UI |
|---------|-------------------|
| Кнопки | `tuiButton` (appearance: primary / outline / ghost) |
| Поля ввода | `<tui-textfield>` + `<input tuiTextfield>` |
| Теги/бейджи | `[tuiChip]`, `[tuiBadge]` |
| Иконки | `<tui-icon icon="@tui.*">` |
| Ошибки валидации | `<tui-error formControlName>` |

### Цвета (CSS-переменные Taiga UI)
- Акцент: `--tui-text-action`
- Фон страницы: `--tui-background-base-alt`
- Карточки: `--tui-background-base`
- Опасность/ошибка: `--tui-status-negative`
- Предупреждение: `--tui-status-warning`

### Типографика
- Заголовки: `font-weight: 700`, `font-size: 1–1.5rem`
- Тело: `font-size: 0.875–1rem`
- Моноширинный шрифт для паролей
