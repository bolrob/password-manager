# План разработки: PassVault — Менеджер паролей

## Цель проекта

PassVault — веб-приложение для безопасного хранения учётных данных с генерацией паролей, категоризацией, поиском и историей изменений. Реализовано на Angular 21 с Taiga UI 5.

---

## Основные пользовательские сценарии

1. **Авторизация** — пользователь регистрируется / входит в систему; данные других пользователей недоступны.
2. **Управление записями** — создание, просмотр, редактирование и удаление учётных данных с логином, паролем, URL, категорией и тегами.
3. **Генерация и оценка паролей** — пользователь генерирует надёжный пароль с настройками длины и набора символов; видит индикатор надёжности.
4. **Поиск и фильтрация** — поиск по названию и логину, фильтрация по категории и флагу «устаревший».

## Риски и способы снижения

| Риск | Вероятность | Снижение |
|------|-------------|---------|
| Несовместимость Taiga UI 5 API с ожидаемыми компонентами | Высокая | Читать `.d.ts` файлы пакета перед использованием; не полагаться на документацию старых версий |
| Сложность настройки MSW с Angular dev-сервером | Средняя | Инициализировать worker до `bootstrapApplication`; использовать `onUnhandledRequest: 'bypass'` |
| Потеря данных при перезагрузке (in-memory mock) | Средняя | Хранить mock-данные в модульной переменной; для production — localStorage или реальный API |
| Размер бандла > 1 МБ из-за Taiga UI | Средняя | Использовать lazy loading для всех маршрутов; OnPush везде; проверять `ng build --stats-json` |
| Lighthouse < 80 по SEO | Низкая | Добавить мета-теги, семантический HTML, aria-атрибуты |
